Primeira Experiência Com Criação De Site

A primeira experiência que tive com HTML foi durante uma atividade de bootcamp. Nela, criei uma página hospedada pelo GitHub onde incluí arquivos PDF e imagens. O único detalhe foi que a experiência não teve instruções profundas, o que me deixou com um conhecimento inicial limitado sobre outras estruturas e funções adicionais.
